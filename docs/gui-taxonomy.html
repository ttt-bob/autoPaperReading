1. 端到端流程关系图：GUI Agent 从任务到验证

Data / Benchmark

截图、DOM/A11y、轨迹、人类演示、任务模板、成功检查器。定义训练和评测边界。

→
Observation

把屏幕转成 screenshot tokens、OCR、UI tree、SoM 标记或结构化上下文。

Perception / Parsing

检测文本、图标、控件、区域、布局块，形成可引用的屏幕状态。

Semantic Understanding

理解每个区域/按钮的角色、功能、状态和用户意图相关性。

Grounding

把自然语言目标映射到元素 ID、点、bbox 或局部高分辨率区域。

Action Interface

输出 click/type/drag、API、PyAutoGUI、Selenium、ADB 或动作 JSON。

Task / User Intent

用户目标、上下文、历史状态和约束条件进入 planner。

Planning / Memory / Exploration

任务拆解、界面探索、技能记忆、反思恢复，持续调用 perception 与 grounding。

Verification / Safety Gate

执行前后检查权限、风险、不确定性、状态谓词和任务完成度。

Environment

真实网页、桌面、移动端、虚拟机、软件沙箱或 MCP 工具环境。

Feedback loop: 环境状态和验证结果返回给 planner；成功/失败轨迹进入 SFT、RL、RFT、reward model、test-time scaling 和数据再生成。
