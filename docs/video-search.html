1. 端到端流程关系图：从视频到答案 / 告警

Data / Benchmark

视频数据集、异常/检索/问答基准、标注与指标。定义评测边界。

→
Video Encoding

帧采样、视频 token、稠密预测、向量表征，把连续画面变成可计算表示。

Retrieval

文本-视频/行人匹配、重识别、以文搜人、部分相关视频检索。

Temporal Grounding

时序定位、事件切分、证据片段，回答“发生在哪一段”。

Human Understanding

姿态估计、动作识别、运动分割，理解人“在做什么”。

Anomaly Judgment

异常打分：摔倒、奔跑、偷盗、闯入等偏离常态行为的判定与定位。

Query / User Intent

自然语言描述（人、动作、场景、组合条件）进入搜索意图解析。

Planning / Routing

查询改写、路由到检索/定位/问答模块、长视频分段与稀疏采样。

Verification / Safety

结果可信度与证据核对、误报抑制、隐私与合规检查。

Environment

监控摄像头、行车记录仪、视频库、边缘设备或 PTZ 相机。

Feedback loop: 答案/告警与证据返回用户；误报/漏报轨迹回流到检索、异常与定位模块的重训练。

状态表达

5. 综述锚点

视频搜索方向目前还没有统一综述，本页把收录论文按 8 层流程组织成一份可浏览地图（含图像检索与跨模态检索）。要实现“检测视频中出现的人、摔倒/奔跑/偷盗行为、乃至戴着黄帽子偷电瓶的人”这类复合查询，典型组合路径是：03 检索（以文搜人/图像） + 05 姿态/动作理解 + 06 异常检测 + 04 时序定位（输出片段），长视频场景再由 07 视频 LLM 兜底推理、08 边缘部署 落地。
